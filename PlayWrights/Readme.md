# 🎭 What is Playwright?

**Playwright** is a free and open-source framework for **web automation and testing**, created by **Microsoft**.

## 🚀 Applications

Playwright can be used for:

- 🌐 Web browser applications
- 📱 Mobile web applications
- 🔌 API testing

## 💻 Supported Languages

Playwright supports multiple programming languages:

- JavaScript
- TypeScript
- Python
- Java
- .NET (C#)

## 🌐 Supported Browsers

Playwright supports all major modern browser engines:

### 1. Chromium
- Google Chrome
- Microsoft Edge
- Other Chromium-based browsers

### 2. WebKit
- Safari browser engine

### 3. Firefox
- Mozilla Firefox

Playwright can run browsers in:

- **Headed mode** → Browser window is visible
- **Headless mode** → Browser runs in the background without opening a window

# 🎭 Features of Playwright

Playwright provides many features that make web automation and testing easier.

## 🚀 Main Features

### 1. 🆓 Free & Open Source
Playwright is free to use and its source code is publicly available.

### 2. 🌐 Multi-Browser
Playwright supports multiple modern browser engines:

- Chromium
- Firefox
- WebKit

### 3. 💻 Multi-Language
Playwright supports:

- JavaScript
- TypeScript
- Python
- Java
- .NET (C#)

### 4. 🖥️ Multi-OS
Playwright can be used on different operating systems:

- Windows
- Linux
- macOS

### 5. ⚙️ Easy Setup and Configuration
Playwright provides simple installation and configuration for automation projects.

### 6. 🧪 Functional Testing
You can automate and test user actions such as:

- Login
- Signup
- Form submission
- Button clicks
- Navigation
- File upload
- Searching

### 7. 🔌 API Testing
Playwright can also be used to test APIs.

You can:

- Send GET requests
- Send POST requests
- Send PUT requests
- Send DELETE requests
- Validate API responses

### 8. ♿ Accessibility Testing
Playwright can be used with accessibility testing tools to check whether web applications are accessible to users with disabilities.

### 9. 📊 Built-in Reporters
Playwright provides built-in reporting options to see test results.

Examples:

- HTML Report
- List Reporter
- Line Reporter
- JSON Reporter
- JUnit Reporter

You can also create **custom reporters**.
