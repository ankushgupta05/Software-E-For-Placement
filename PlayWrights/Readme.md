# 🎭 What is Playwright?

**Playwright** is a free and open-source framework for **web automation and testing**, created by **Microsoft**.

## 🚀 Applications

Playwright can be used for:

- 🌐 Web browser applications
- 📱 Mobile web applications
- 🔌 API testing

## 💻 Supported Languages

Playwright supports multiple programming languages:

- JavaScript
- TypeScript
- Python
- Java
- .NET (C#)

## 🌐 Supported Browsers

Playwright supports all major modern browser engines:

### 1. Chromium
- Google Chrome
- Microsoft Edge
- Other Chromium-based browsers

### 2. WebKit
- Safari browser engine

### 3. Firefox
- Mozilla Firefox

Playwright can run browsers in:

- **Headed mode** → Browser window is visible
- **Headless mode** → Browser runs in the background without opening a window
